# .github

Shared issue and PR templates, and other community health files. See [GitHub documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for more details.

The `.github/labels.json` file is the source-of-truth for GitHub labels configured across all of my personal repositories. The "push-labels" workflow, running in GitHub Actions, will automatically sync the labels in this file to the labels configured for this repository in GitHub. Overnight, workflows for my other repositories will also sync their labels to match the labels of this repository.
